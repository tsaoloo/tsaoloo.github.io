THE COLLECTION

收藏理念

松仁草廬・東方古典藝術

以藝術作品與日常空間為起點，沿著木、石、陶與造像，慢慢看見材料與工藝的不同表情。

松仁草廬承接觀古今舊站所記錄的收藏脈絡，重新整理為以東方古典藝術、佛教造像、木藝與手珠為主的展示空間。舊文所述歷史地址、交易承諾與聯絡方式不代表目前資訊；本頁只保留藝術內容與收藏觀點。

01 / COLLECTION

沉香

沉、檀、龍、麝，沉香為萬香之首，品香不只是生活意趣的建立，也是養心修行之精神洗禮，更是追求心靈超越的捷徑。

02 / COLLECTION

藝術精品

藝術乃形而上的心靈追求…做收藏和做生意一樣，必須知道質感是什麼？要懂得選擇最高级的…至少你得看懂它！

03 / COLLECTION

頂級手珠串

石有"磁場"，木有"氣場"宗教上普遍認為"佩珠"能避邪袪煞，化解負面的磁場，"盤珠"能集中精神，去除雜念，療癒不安心理，而手持"念珠"誦念，可以增定力、生智慧，令心神專注，讓心靈覺醒，使心能量完全提升。

04 / COLLECTION

根雕

是『七分天然，三分人工』之作，是溶抽象、意象與具象的真美融合， 令人驚喜，百看不厭！

05 / COLLECTION

石灣陶

是中國傳統的陶瓷領域，展現古樸高雅、深刻雋永的藝術品味，相當耐人尋味。

06 / COLLECTION

原木及其創作

主要用材為台灣最珍貴的牛樟、檜木、櫹楠、櫸木等之天然風化木，並提供名家生活實用及藝術創作品。

07 / COLLECTION

文物字畫等雜項

則偏重於過去生活領域中找尋有味道的老東西，也發掘一些有潛力新秀的現代作品。

肖楠手珠交流

鑑於現今香木市場上贗品充斥，良莠不齊，而且大多紙上談兵，一人一套經，不是道聽塗說，就是以偏概全，而悖理客觀事實亦所在多有，在眾說紛紜下，讓正確知識無法傳遞，實深感遺憾！今特拋磚引玉、以饗同好，祈願對整個文化市場有所助益，亦盼各方賢達不吝賜教！

藝術精品

本店針對沉香、石灣陶、文物字畫、頂級手珠串，努力找尋各領域的名家精品，並篩選過濾，去蕪存菁，提供您優質的品味生活，更豐富您的投資收藏。

觀古今藝術與生活

生活可以是平凡、平淡的，也可以是激烈、昂揚的。在歷經平凡、平淡或激烈、昂揚的生活後，期盼的該是寧靜、安祥的境界。

那麼該如何朝著寧靜、安祥這條道路前進呢？除了宗教之外，透過『藝術』的追求，或許就是最好的處方。

『藝術生活』的領域很廣：音樂、舞蹈、戲劇、繪畫、雕刻、插花、設計 ……等，可說五花八門，爭妍鬥豔，每個人可依循自己的興趣及才能去發展。坦白說，每一門『藝術』的領域，都有很深的學問，想達到一定的程度，常須從小培養及鑽研，所以並不是每一個人都能在『藝術』的領域有所成就。

雖然大部份人無法從事『藝術』的工作，卻是可以培養欣賞的興趣，從其中感受『藝術生活』的滋味。這種精神境界的追求，正是朝向寧靜、安祥生活大道的方向。

一場音樂饗宴、一齣動人戲劇、一幅美好繪畫、一件神奇雕刻、一塊天然奇木 ……等，在您欣賞，甚至進一步擁有時，常能讓您的心靈得到淨化、感動，而這正是『藝術生活』的追求。 『藝術』追求的是真善美，從事『藝術』的孩子不容易變壞。

學會欣賞『藝術』的人生，也會變得更美好。期盼有緣的您，也能朝著這條道路不斷邁進，讓您的人生因『藝術』的接觸而更美滿。
